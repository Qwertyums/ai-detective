# Журнал использования ИИ

Подписка ChatGPT 28 октября 2026 года: добавлен отдельный OAuth-вход для локального приложения, PKCE и проверка ID-токена через JWKS; callback принимает только ожидаемый state. Сессии шифруются Windows DPAPI, refresh сериализован между процессами, аккаунты и способы оплаты разделены в результатах. Добавлен отдельный потоковый транспорт по официальным ограничениям маршрута подписки. При отказе или лимите нет переключения на платный API. OAuth, обновление, отзыв, модельный каталог и SSE проверяются с вымышленными токенами; реальное согласие пользователя и доступность его подписки не вымышляются.

Переход на API 28 октября 2026 года: по просьбе пользователя локальная Qwen заменена на OpenAI Responses API со строгой JSON-схемой, ключом из .env/окружения и учётом API usage. Старые попытки локальной модели сохраняются как исторические; они не являются API-результатами. До настройки ключа интеграция проверяется настоящим SDK с локальным тестовым HTTP-транспортом, без оплачиваемых запросов.

Дополнение 28 октября 2026 года к эпизоду 9: после сообщения пользователя о пропущенных status, confidence и explanation добавлен один запрос на исправление JSON с исходным контекстом и ошибками проверки. Все попытки сохраняются, затраты суммируются; недостающие содержательные поля не подставляются автоматически. Реальный пробный запрос выявил также имя поля без кавычек и недоступный evidence_id. Для первого добавлена явно фиксируемая нормализация синтаксиса, второй остаётся ошибкой валидации. Из промпта убран пример с конкретным ID; допустимые ID теперь перечисляются в запросе. Проверки включают повторный невалидный ответ, сохранение значений при нормализации и недоступность модели.

В условии есть необычная формулировка «правдоподобная, но доказанная связь». Эпизод 5 фиксирует проверяемый отказ от недоказанной причинной связи; отдельная доказанная составная связь — Q3: две отметки времени и базовая норма дают сравнение длительности с лимитом. Команда должна самостоятельно подтвердить эталоны и не приписывать себе проверки, которые не проводила.
